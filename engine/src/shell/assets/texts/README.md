# 引擎外壳文字

`zh-CN.json` 是外壳页面（首页 / 设置 / 关于 / 选 Mod / 读档 / 游戏内菜单）的
用户可见文字。代码里保留同样的中文默认值：文件缺失、JSON 损坏或某个键缺失时，
会退回代码兜底，不会让界面崩溃。

打包成 one-folder 后，可以把 `shell/assets/texts/zh-CN.json` 放在 exe 旁边；
它优先于内置副本，改完重启程序即可生效，不用重新打包。

引擎名 / 版本 / demo 标签仍由 `core/version.py` 管，不放进这里。
动态消息（例如“已存档：xxx”）暂时还在代码里，后续可以按模板键逐步迁移。
